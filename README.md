# 🎒 초등 2학년 신나는 구구단 연습 게임

초등학교 2학년 학생들을 위한 귀엽고 재미있는 웹 기반 구구단 퀴즈 게임입니다!

## ✨ 주요 기능
- **2단부터 9단까지 무작위 출제**: 앞자리 2~9단, 뒷자리 1~9 무작위 문제 생성 (예: `3 × 7 = ?`)
- **초등 맞춤형 피드백**:
  - 정답 시: 커다란 **"🎉 정답! 참 잘했어요! 🎉"** 문구 및 색종이 폭죽 효과
  - 오답 시: **"아쉬워요! 정답은 ___이에요."** 친절한 정답 안내 문구
- **편리한 입력**: 숫자 입력창 & 마우스 클릭 및 키보드 `Enter` 키로 편리한 진행
- **동기부여 요소**: 푼 문제 수 및 연속 정답(스트릭) 카운트 제공
- **반응형 디자인**: PC 모니터는 물론 태블릿, 스마트폰에서도 깔끔하고 큼직하게 표시

## 🚀 플레이 방법
1. 브라우저에서 `index.html` 파일을 열거나 배포된 GitHub Pages 링크로 접속합니다.
2. 문제의 정답을 빈칸에 입력하고 **[확인]** 버튼 또는 `Enter` 키를 누릅니다.
3. 정답 여부를 확인한 후 **[다음 문제 풀기 ➡️]** 버튼 또는 `Enter` 키를 눌러 다음 문제로 넘어갑니다!
